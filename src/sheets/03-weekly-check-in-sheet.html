Weekly Fifteen-Minute Check-In

One page, one week, fifteen honest minutes

How to use this sheet, kindly

Print one per week, per person. Fill yours before the call so the call is for talking, not remembering. Two wins and one wobble is a full week's report. If you skipped everything, write "skipped everything" — that counts as showing up.

During the call (10 minutes together)

  • Each person shares: wins, wobble, one small next thing. (7 min)
  • Ask once: "What would help this week — advice, or just listening?" (2 min)
  • Confirm next week's time. (1 min)
